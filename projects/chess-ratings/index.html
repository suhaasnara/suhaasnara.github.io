My Chess Rating, 2009–2026

Every US Chess rated section I've played, from my first tournament in 2009 to National Master, pulled from the US Chess ratings database and turned into an interactive chart for my chess site.

Data
US Chess ratings API, 177 rated sections
Built
October 2026
Tools
JavaScript, SVG, JSON
Live
On the chess site
The chart

2009 to today

    Where and when

    Mostly Colorado, then Philadelphia

    How it's built

    From the ratings database to the page

    Pull

    The US Chess ratings site loads its data from a public API. I pulled every page of my rated sections from it. Browsers block the chess site from calling that API directly (no CORS), so the data is saved as a JSON snapshot.

    Clean

    One row per rated section, with the date, event, state, and post-event regular, quick, and blitz ratings. Milestones are stored next to the data, and the stats on the page are checked against official US Chess records.

    Draw

    Plain SVG and JavaScript, no chart library. Regular, quick, and blitz toggles; a compressed axis break for 2019–2023; hover, tap, and arrow-key support; and a full table of results underneath.
